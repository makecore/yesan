# 국가예산 나침반 (yesan)

국립중앙도서관 직원이 국가 예산사업을 **기획·요구·심의·집행·성과관리**할 때 필요한 규정과 마감일을 한곳에서 확인하는 웹 도구입니다.

- 기준일: **2026-10-26** (국가법령정보센터 현행 원문 대조)
- 법률자문이나 최종 판정이 아닌 **1차 실무 참고용**입니다. 최종 판단은 소관 부서와 최신 원문으로 확인하세요.

## 주요 기능

| 기능 | 하는 일 |
|---|---|
| 마감 D-day | 첫 화면에서 다가오는 법정기한·내부 마감 4건과 남은 날짜를 보여줍니다. |
| 연간 일정 | 이번 달부터 12개월의 법정기한을 월별로 보여줍니다. 기관 내부 마감을 직접 추가하고, 캘린더 파일(.ics)로 내려받아 아웃룩·아이폰에 등록할 수 있습니다. |
| 규정 탐색기 | 신규/계속, 총사업비, 국고, 당해연도 사업비, 사업 성격을 입력하면 예타·총사업비 관리·정보화 사전협의·SW 대기업 참여제한 해당 여부를 판정합니다. |
| 단계별 체크리스트 | 입력값에 맞춰 기획 → 요구·편성 → 심의 → 집행 → 성과·결산 단계의 할 일을 만들어 줍니다. 체크 상태는 브라우저에 저장됩니다. |
| 자료실 | 법령·지침·서식 원문 링크 모음입니다. |
| AI 작업지시서 | 입력값과 판정 결과를 정리한 프롬프트(AI에게 주는 지시문)를 만듭니다. |

> 저장 기능(체크 상태, 내부 마감, 입력값)은 **각자의 브라우저에만** 저장됩니다. 다른 직원과 공유되지 않으며, 브라우저 기록을 지우면 사라집니다.

## 파일 구조

```
index.html     화면 뼈대
styles.css     디자인
js/data.js     기준 데이터(법령 링크, 법정 일정, 달라진 기준) ← 기준이 바뀌면 여기를 고칩니다
js/app.js      동작(판정 규칙, 일정 계산, 체크리스트)
```

## 기준이 바뀌었을 때 고치는 곳

| 바뀐 것 | 고칠 파일·위치 |
|---|---|
| 편성 세부지침 연도·링크 | `js/data.js`의 `LINKS.guide2027`, `SOURCES` |
| 법정 제출기한 | `js/data.js`의 `LEGAL_DEADLINES` |
| 예타·총사업비·사전협의·SW 하한 금액 | `js/app.js`의 `analyze()` 함수 |
| 기준일 | `js/data.js`의 `BASIS_DATE` |

## 실행 방법

설치나 빌드(코드를 변환하는 작업)가 필요 없는 정적 웹사이트(서버 없이 브라우저만으로 열리는 페이지)입니다.

- **내 컴퓨터에서 보기:** `index.html`을 더블클릭해 브라우저로 엽니다.
- **인터넷 주소로 공유하기:** GitHub Pages(깃허브가 무료로 제공하는 웹 호스팅)를 켜면 `https://makecore.github.io/yesan/`에서 열립니다.
